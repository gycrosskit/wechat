# 0.1.9-rc.1（2026-10-23）

- 转账受理即释放发送槽，保留最多 64 笔不阻塞的进程内回执关联；清理与迟回执不影响新请求。
- 唯一 SDK 按实际 Ability 刷新后继请求 context，异步准备固定请求 owner。

# 0.1.8-rc.1（2026-10-18）

- 修复 SDK 提交完成前到达的 OAuth、网页分享与转账确认页回执，避免已消费回执被再次恢复为 pending。
- 清理期间保留原 owner 资格，隔离旧 cancel、owner 替换与回执重入，避免清除新请求。
- 独立 HAR RC，继续配套 Maven `0.1.9` 与 Git Pod / SPM `native-0.1.9`；真实微信业务另行验收。

# 0.1.7（2026-10-16）

- 普通图片分享仅等待 SDK 受理，随后释放提交占用，不写业务 pending 或等待最终分享回执。
- 图片文件独立保留到精确匹配回执；发送失败、未发送取消仍清理，迟回执不影响新请求。
- 已受理后的 ImageSource 释放失败不改为分享失败。
