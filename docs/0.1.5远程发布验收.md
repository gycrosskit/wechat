# 0.1.5 线程边界修复验收

发布准备中；本文件将随远程门禁结果更新，不代表当前坐标已经可用。

Android 构造、Unit 请求、监听与取消自带 Main 边界；旧同步 Boolean handleIntent 仍要求 Main，后台使用 Result callback 重载。Unit 返回不代表 SDK 受理，宿主必须等 onSubmitted(REQUESTED)，SDK 回执仍需请求归属验证。

源码验证：22 项 Android 和 10 项 JVM 测试通过，Android/OHOS 编译和独立源码 composite API 消费通过。新版远程制品验证待完成；微信签名回跳、真实页面和设备业务由宿主验收。

兼容组合：Maven 0.1.5；OHOS HAR 0.1.4；Swift Package/Git Pod 0.1.3。后两者源码和协议未变，不重新包装或覆盖旧发布。
